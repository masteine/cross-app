# Чекліст релізу v0.1.0-beta

Пункти, позначені **(власник)**, вимагають рішення або дій власника проєкту: акаунти, підписи, публікація, юридичні питання. Агент їх не виконує. Пункти **(CI)** мають проходити автоматично. Тег, публікація і push робляться лише вручну.

## 1. Передумови

- [ ] Злиті гілки Спринтів 6–10 (GUI, графіка й `cross-compat`, шлях без Rosetta, пакетування й телеметрія, стабілізація); `main` зелений.
- [ ] У `main.rs` зареєстровано `cross crash` і panic hook (`cross_core::crash::install`), помилки друкуються через `cross_core::chain_message`. Перевірка: `cross crash list` працює, а `cross deps list --bottle nope` друкує повідомлення без повторів.
- [ ] Усі пункти Спринтів 1–9 у [SPRINT_PLAN.md](../SPRINT_PLAN.md) мають чесні позначки «перевірено / не перевірено».

## 2. Якість коду

- [ ] **(CI)** `cargo fmt --all --check`
- [ ] **(CI)** `cargo clippy --workspace --all-targets -- -D warnings`
- [ ] **(CI)** `cargo test --workspace`
- [ ] Інтеграційні тести на справжньому Wine: `CROSS_TEST_ENGINES_HOME=… cargo test -p cross-bottle --test real_wine -- --ignored --test-threads=1`
- [ ] **(власник)** Створено GitHub-репозиторій, CI (`.github/workflows/ci.yml`) і nightly (`nightly.yml`) хоч раз пройшли на `macos-15`/`macos-26`. Досі жоден workflow не запускався: немає remote.
- [ ] Тріаж відкритих issue: top-20 багів бети виправлено або задокументовано в «Відомих проблемах» release notes.

## 3. Тестова матриця

- [ ] **(власник)** Прогнано [тестову матрицю](test-matrix.md) на M1, M2/M3, M4/M5 (потрібні ігри й Steam-акаунт).
- [ ] Метрика: ≥ 80 % матриці без анти-чіту зелені або жовті.
- [ ] Результати перенесено у профілі `cross-compat` (Спринт 7); для 10 ігор є профілі «з коробки».
- [ ] Шлях «чистий Mac → гра запущена» займає ≤ 15 хвилин без терміналу (GUI, Спринт 6). Заміряно на чистому користувачі macOS.

## 4. Документація

- [ ] README: статус, вимоги, установка (DMG/Homebrew з Спринту 9 замість `cargo install`), посилання на документи.
- [ ] [Швидкий старт](quickstart.md) пройдено «з нуля» за текстом, без підказок.
- [ ] [FAQ](faq.md): терміни Rosetta звірено з актуальною документацією Apple.
- [ ] [Профілі сумісності](compat-profiles.md): усі позначки «[узгодити зі Спринтом 7]» прибрано, формат відповідає `cross-compat`.
- [ ] Release notes: що нового, відомі проблеми (`.msi`/`.lnk`, D3DMetal, corefonts для Steam, 32-біт), як повідомити про помилку.

## 5. Ліцензії

- [ ] **(власник)** Обрано ліцензію cross-app і додано файл `LICENSE`. Зараз у `Cargo.toml` вказано MIT, а файлу немає.
- [ ] [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) актуальний: перегенеровано список Rust-крейтів (з GUI-залежностями Tauri/JS) і звірено версії двигунів у `catalog.json`.
- [ ] Повні тексти ліцензій залежностей (`cargo about generate` або аналог) вкладено в `.app`/DMG.
- [ ] Дистрибутив не містить D3DMetal / GPTK:
      `find <Cross.app або змонтований DMG> \( -iname '*d3dmetal*' -o -iname 'libd3dshared*' -o -path '*lib/external*' \)` повертає порожньо.
- [ ] Якщо двигун Wine вкладено в DMG (рішення Спринту 9): поряд лежать COPYING.LIB (LGPL-2.1), посилання на вихідний код цієї версії Wine і ліцензії вкладених бібліотек. Якщо двигун завантажується з Gcenx, достатньо вказати джерело.
- [ ] **(власник)** Юридичний перегляд THIRD_PARTY_NOTICES і умов Steam перед публічним анонсом.
