# ADR 0002 — Фронтенд GUI: статичні HTML/CSS/JS без пакетного менеджера

- Статус: прийнято (15.10.2026, Спринт 6)
- Контекст: [ADR 0001](0001-gui-framework.md) (Tauri 2), `SPRINT_PLAN.md`, Спринт 6 і 9

## Контекст

ADR 0001 обрав Tauri 2 і залишив на Спринт 6 вибір фронтенд-фреймворку та пакетного менеджера. Обмеження цього спринту: npm/pnpm-пакети не встановлюються (немає дозволу на JS-залежності), а збірка не має залежати від Node. Екранів небагато: бібліотека карток, сторінка пляшки, двигуни, логи, майстер першого запуску, діалог drag-and-drop.

## Розглянуті варіанти

| | Статичні HTML/CSS/JS (ES-модулі) | React/Svelte/Vue + Vite |
|---|---|---|
| Залежності | жодних; `window.__TAURI__` дає API | `node_modules`, lock-файл, оновлення безпеки |
| Збірка | немає: `ui/` вбудовується як `frontendDist` | `vite build` перед `cargo build`, Node у CI |
| `@tauri-apps/api` | глобальний об'єкт (`app.withGlobalTauri`) | npm-пакет з типами |
| Типи | немає (JS) | TypeScript |
| Реактивність, компоненти | вручну: маленький хелпер `h()`, сторінка перемальовується цілком | з коробки |
| Масштабування на десятки екранів | гірше | краще |

## Рішення

Фронтенд — звичайні файли в `crates/cross-gui/ui/` (`index.html`, `styles.css`, `js/*.js` як ES-модулі), без бандлера й пакетного менеджера. Tauri вбудовує їх у бінарник як `build.frontendDist`.

- API Tauri береться з `window.__TAURI__`. Його вмикає ключ `app.withGlobalTauri: true` у `tauri.conf.json`. Ключ перевірено в `tauri-utils` 2.10.2 (`AppConfig::with_global_tauri`), простори імен (`core`, `event`, `window`, `webview`…) — у `tauri` 2.12.4, `scripts/bundle.global.js`.
- Сторінка використовує лише `core.invoke` і `event.listen`, тому capability `default` дає тільки `core:default`. Діалоги (`tauri-plugin-dialog`) і нотифікації (`tauri-plugin-notification`) викликаються з Rust, і їхні JS-дозволи сторінці не видаються.
- Текст потрапляє в DOM лише через `textContent` (хелпер `h()` в `ui/js/ui.js`), бо назви й шляхи приходять із файлів користувача та маніфестів Steam. CSP: `default-src 'self'`, IPC (`ipc:`, `http://ipc.localhost`), картинки `data:` (обкладинки віддаються як data-URL).
- Темна тема — CSS `prefers-color-scheme`; WKWebView бере її з системи.

## Наслідки

- `cargo build -p cross-gui` — уся збірка GUI. Node, `tauri-cli` і `npm install` не потрібні ні для розробки, ні в CI. `tauri-cli` знадобиться лише для `.app`/DMG у Спринті 9.
- Немає TypeScript: контракт команд (назви й аргументи) перевіряють Rust-тести командного шару і ручна звірка. Якщо екранів стане помітно більше, варто перейти на Vite + TypeScript. Код сторінок перепишеться, а Rust-команди лишаться.
- Сторінка перемальовується цілком після кожної дії. Для поточних обсягів цього досить. Живі логи читаються шматками до 256 КБ, а в DOM лишаються останні ~2 МБ тексту.
- JS перевіряється лише вручну: `node --check` і перегляд у браузері з підставним `window.__TAURI__`. Автотестів фронтенду немає.
