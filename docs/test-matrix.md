# Тестова матриця v0.1 — шаблон і результати

Цей документ — робочий шаблон для прогону тестової матриці з розділу 3 [SPRINT_PLAN.md](../SPRINT_PLAN.md) на M1, M2/M3 і M4/M5 перед релізом v0.1.0-beta.

> **Статус на 15.10.2026: матрицю не прогнано.** Для неї потрібні справжні ігри, Steam-акаунт власника з цими іграми і кілька Mac різних поколінь. Агент розробки цього зробити не може. Нижче всі результати мають статус «не тестувалось».

## 1. Критерії

| Статус | Критерій |
|---|---|
| **зелений** | запуск без ручних дій (лише `cross steam launch` / `cross run`, з профілем, якщо є); стабільні **30+ FPS на M1, 1080p, середні налаштування**; 15 хвилин гри без падінь |
| **жовтий** | запускається, але потрібні ручні дії, або FPS нижче порогу, або є помітні артефакти чи нестабільність |
| **червоний** | не запускається, падає в перші 15 хвилин або неграбельна |
| **червоний (очікувано)** | анти-чіт або відомий not-a-goal; перевіряємо лише, що cross-app чесно це показує |
| **не тестувалось** | — |

Метрика успіху v0.1 (розділ 4 плану): **80 % матриці без анти-чіту — зелений або жовтий.**

## 2. Підготовка машини (один раз на Mac)

```bash
cross doctor --json > doctor-<чип>.json    # додається до результатів
cross engine install wine-devel-11.18 --dxvk
cross engine import-gptk ~/Downloads/Game_Porting_Toolkit_<версія>.dmg   # для DX12
cross bottle create steam
cross steam install steam
cross steam run steam                      # увійти, встановити ігри з матриці
cross deps install steam dxvk vcrun2022
```

Записати: модель Mac і чип, обсяг RAM, версію macOS, версію cross (`cross --version`), двигун, версію GPTK.

## 3. Процедура для кожної гри

1. Перший запуск **без профілю**: `cross steam launch steam <appid>` (або `cross run …` для не-Steam).
2. FPS: Metal HUD (`--metal-hud` для `cross run`; для Steam-ігор: `cross steam profile steam <appid> --env MTL_HUD_ENABLED=1`). Налаштування гри: 1080p, середні.
3. 15 хвилин гри: меню, збереження, завантаження, звук, ввід (клавіатура, миша, геймпад за наявності).
4. Якщо не зелений: підібрати профіль ([compat-profiles.md](compat-profiles.md#3-як-написати-профіль-для-гри)) і повторити.
5. Записати результат у форматі розділу 5; лог: `~/Library/Application Support/cross-app/bottles/steam/logs/steam.log`.

## 5. Формат запису результату

Один запис на пару «гра × Mac». Записи складаються в розділ 6 цього файлу (або окремим файлом `docs/test-results/<дата>-<чип>.md`), а підсумок переноситься в таблицю розділу 4 і в профіль `cross-compat`.

```markdown
### <Гра> (<appid або "не Steam">) — <чип>, <дата РРРР-ММ-ДД>

- Статус: зелений | жовтий | червоний | червоний (очікувано)
- Mac: <модель>, <чип>, <RAM> ГБ, macOS <версія>
- cross: <cross --version>, двигун <id>, GPTK <версія або "немає">
- Бекенд: d3dmetal | dxvk | wine (вбудований)
- Налаштування гри: 1080p, середні
- FPS: середній <N>, мінімальний <N> (Metal HUD)
- Ручні дії: немає | <перелік>
- Профіль: немає | <що змінено: backend, deps, env, args>
- Проблеми: <падіння, артефакти, звук, ввід, Steam overlay …>
- Лог / issue: <посилання>
- Тестувальник: <нік>
```

Той самий набір полів є в шаблоні issue «Звіт про сумісність гри», тож результати зовнішніх тестувальників переносяться сюди без переписування.
